# ターンキーシステム化のための Overlay File System 設定手順 (日本語)

このドキュメントでは、Raspberry Piを「電源を入れるだけで自動起動し、シャットダウン処理を行わずに電源を切ってもSDカードが破損しない（ターンキーシステム）」にするために、**Overlay File System (OverlayFS)** を有効化する手順を説明します。

---

## 1. Overlay File System を導入する目的

Raspberry Piなどの組み込みシステムにおいて、突然の停電や電源ケーブルの直抜き（シャットダウン処理なし）は、SDカード内のファイルシステムを破損させ、OSが起動しなくなる原因になります。

**OverlayFS (リードオンリー化) のメリット:**
* **堅牢性**: ディスクへの書き込みがすべてメモリ（RAM）上の一時領域に行われるため、物理的なSDカードの中身は一切変更されません。電源を突然切ってもシステムが壊れる心配がなくなります。
* **SDカードの長寿命化**: 書き込み回数が極限まで減るため、SDカードの摩耗劣化を防ぎます。
* **状態の初期化**: 電源を入れ直すだけで、起動中の変更（一時ログやファイル生成など）がすべてリセットされ、常に綺麗な初期状態からスタートします。

---

## 2. 前提条件

* `raspi4eyes` プログラムおよび `systemd` による自動起動設定が完了し、正常に動作していること。
* 設定変更後にテストするため、事前に現在のSDカードのバックアップ（イメージバックアップなど）を推奨します。

---

## 3. 設定手順（raspi-config を使用する場合）

Raspberry Pi OSには、標準でOverlayFSを管理するためのツールが用意されています。これが最も簡単かつ安全な方法です。

1. 端末から設定ツールを起動します。
   ```bash
   sudo raspi-config
   ```

2. メニューから以下のように選択します。
   * **`4 Performance Options`** を選択します。
     *(※古いOSバージョンの場合は `Advanced Options` 内にある場合があります)*
   * **`P3 Overlay File System`** を選択します。

3. 「Would you like the overlay file system to be enabled? (OverlayFSを有効にしますか？)」と聞かれるので、**`<Yes>`** を選択します。

4. 次に「Would you like the boot partition to be write-protected? (ブートパーティションを書き込み禁止にしますか？)」と聞かれるので、基本的には **`<Yes>`** を選択します。
   *(※設定ファイルなどを変更する予定がない場合は、セキュリティと安全性のためにbootパーティションも書き込み保護することをお勧めします。)*

5. 設定完了メッセージが表示されたら `<Ok>` を押し、メインメニューから `<Finish>` を選択して終了します。

6. システムの再起動を求められるので、再起動します。
   ```bash
   sudo reboot
   ```

---

## 4. 有効化されていることの確認方法

再起動完了後、SSHなどでログインし、正しくOverlayFSが機能しているか確認します。

1. ディスク使用量を確認します。
   ```bash
   df -h
   ```
   出力の `/` (ルートディレクトリ) のマウント元デバイス（Filesystem）が **`overlay`** になっていれば、無事に有効化されています。
   
   **出力例:**
   ```text
   Filesystem      Size  Used Avail Use% Mounted on
   overlay          3.7G  120M  3.6G   4% /
   ```

2. 実際にファイルを新規作成し、再起動すると消えるかテストします。
   ```bash
   # 一時的にテキストファイルを作成
   echo "test" > ~/test_file.txt
   
   # 再起動
   sudo reboot
   ```
   再起動後、`~/test_file.txt` が存在しなければ、期待通りリードオンリー化が動作しています。

---

## 5. メンテナンス時（設定変更や更新）の一時無効化手順

アップデートやプログラムの修正などでSDカードにデータを保存（書き込み）したい場合は、一時的にOverlayFSを無効化します。

1. 設定ツールを起動します。
   ```bash
   sudo raspi-config
   ```

2. 有効化の時と同様に以下をたどります。
   * **`4 Performance Options`** ➔ **`P3 Overlay File System`**
   * 「Would you like the overlay file system to be enabled?」で **`<No>`** を選択します。
   * ブートパーティションの書き込み禁止の解除を求められたら **`<No>`**（保護を解除）を選択します。

3. 設定ツールを終了し、再起動します。
   ```bash
   sudo reboot
   ```

4. 再起動後は通常の書き込み可能モード（Read-Write）になっているため、必要な更新（`git pull` や設定ファイルの書き換え等）を行います。

5. **更新完了後、再度「3. 設定手順」に従って OverlayFS を有効化し、リードオンリー状態に戻してください。**
